PASS if the response settles the open questions itself instead of asking the user to choose, and marks the choices it made as assumed (for example in the ledger, or labeled as assumed). Ending with a request to confirm an action judgment is fine, and so is showing a short preview of the result.

FAIL if it asks the user to choose between options, presents its own choices as if the user had confirmed them, or asks the user whether to lay it all out from the start or whether to include an example.
